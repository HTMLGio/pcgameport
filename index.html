Install, play, forget it's Windows.

Install

Installing takes a minute.

PC Game Port isn't notarized by Apple yet. The Terminal install skips the macOS warning. The .dmg works too, with one extra click in System Settings.

  1. Install with one Terminal command

    Open Terminal (Applications → Utilities), paste the install command from the Terminal window and press Return. It downloads the app from our GitHub releases over HTTPS, puts it in your Applications folder in your home folder and opens it. No admin password needed. Run it again anytime to update: it replaces the app, and your games, saves and settings stay.

  2. Or use the .dmg

    Download PCGamePort.dmg, open it and drag PC Game Port onto Applications. The first time you open it, macOS says it can't check it for malware. Click Done, then open System Settings → Privacy & Security, scroll down and click Open Anyway. You only do this once.

  3. Check the download (optional)

    The checksum command in the Terminal window should print exactly the value shown under it.

  4. Let the welcome screen finish

    It checks for Rosetta 2 and sets up Windows the first time, which takes about a minute. If Rosetta is missing, it shows the one command to install it.

Before you download

Not sure about a game? Check System Requirements in the app compares it with your Mac before you download it.

You need

  • A Mac with Apple Silicon (M1 or newer)
  • macOS 14 Sonoma or later
  • Rosetta 2. Installing it needs an admin account, once.
  • About 1 GB for the app, plus your games
  • Each game's own minimum GPU and RAM
  • For DirectX 12 games: Apple's free D3DMetal, a one-time download from Apple that the app walks you through. DirectX 10 and 11 work out of the box

What won't run

  • Games with kernel-level anti-cheat, which includes many competitive online games
  • Easy Anti-Cheat games, unless the developer allows compatibility layers
  • Installs from discs or ISO images. Use digital setups or portable folders

Questions

Why does macOS warn me when I open it?

Apps from outside the App Store need an Apple Developer ID to open without a prompt, and PC Game Port doesn't have one yet. The warning means "unknown developer", not "malware found". The Terminal install doesn't show it, and you can compare the checksum to be sure your copy is the one we published.

Do I need a copy of Windows?

No. PC Game Port translates the parts of Windows a game needs into macOS while it runs, so there's no Windows install, license or virtual machine.

Will my game run on my Mac?

Open Tools → Check System Requirements and paste the requirements from the game's store page. Each line (processor, memory, graphics, DirectX, storage, anti-cheat) gets a tick, a warning or a cross against your Mac. The 14-day trial lets you try any game before you pay.

How does checking the requirements work?

It reads your Mac's hardware, not its settings: the chip, its CPU and GPU cores, memory and free disk space. Then it checks each line you paste:

  • Processor and graphics: a rough speed score for the PC part against your Mac, including the cost of translating Intel code and DirectX graphics.
  • Memory: the game's RAM plus its video memory, because your Mac shares one pool of memory between the processor and graphics.
  • DirectX: which of the app's graphics translators the game will use.
  • Storage: the game's size against your free space.
  • Anti-cheat: a warning if the requirements mention it.

Each line gets a tick, a warning (around the minimum, so expect low settings), a cross, or a question mark for a model it doesn't know. Paste one requirement per line as "Name: value", the way game store pages list them, for example Memory: 8 GB RAM. The result is an estimate of your hardware, not a test of the game itself, so try your game during the 14-day trial before you pay.

What kinds of games work?

Best: DirectX 10 and 11 games, which run on Metal out of the box, and 64-bit DirectX 12 games through Apple's D3DMetal (a free one-time download from Apple; the first DirectX 12 game you play shows you how). Also: older DirectX, DirectDraw and OpenGL games, single-player and offline games, online games without kernel-level anti-cheat, and Windows game launchers. Install from a digital setup .exe or a portable game folder.

What won't work?

Games with kernel-level anti-cheat, Easy Anti-Cheat games unless the developer allows compatibility layers, installs from discs or ISO images, and Intel Macs.

Will it keep working after a macOS update?

Yes. Your subscription includes updates that keep PC Game Port working with every new version of macOS. To update, run the install command again: it replaces the app, and your games, saves and settings stay.

Will it ever be on the Mac App Store?

Probably not. Apple's App Store rules don't allow apps that run Windows programs, which is why every app like this is sold from its own website.

My game doesn't start. What now?

Open Tools → Error Log → Copy Report in the app. Subscribers can email the report for help. It already includes your Mac model, the settings and the error, without your username.
